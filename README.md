# 🎓 CollegeHub

A modern College Discovery Platform (Frontend) built with **Next.js**, **TypeScript**, and **Tailwind CSS** that helps students explore colleges, compare institutions, save favorites, and receive rank-based college recommendations.

## 🚀 Live Demo

**Live Website:** [https://collegehub-frontend-mwsdd6pvp-aditi-collegehub.vercel.app?_vercel_share=HgBCZ8XUacszAWmUMDzX9DuI4VXiCMHd]

**GitHub Repository:** [https://github.com/Ziggyyyyyyyy/collegehub-frontend.git]

---

## 📌 Features

### 🔍 College Discovery

* Browse a curated list of colleges
* View detailed college information
* Explore ratings, rankings, and locations

### ⚖️ College Comparison

* Compare multiple colleges side-by-side
* Analyze key metrics before making decisions

### ⭐ Save Favorites

* Bookmark colleges for future reference
* Quickly access saved institutions

### 🎯 College Predictor

* Enter exam details and rank
* Get personalized college recommendations
* Simple rank-based prediction engine

### 📱 Responsive Design

* Optimized for desktop, tablet, and mobile devices
* Modern and clean user interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/collegehub-frontend.git
```

### Navigate to Project Directory

```bash
cd collegehub-frontend
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🏗️ Build for Production

```bash
npm run build
npm start
```
